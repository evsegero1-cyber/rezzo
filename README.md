# Chevrolet Rezzo 3D Academy

Android-приложение для изучения устройства **Chevrolet Rezzo 2005, 1.6 л (1598 см³), 16V, МКПП-5, передний привод**:
интерактивная 3D-модель, справочник по деталям, характеристики с указанием достоверности.
Работает полностью офлайн.

## Что работает сейчас (этапы 1–3)

- **3D-сцена** (Filament + glTF): вращение, масштаб, виды спереди/сзади/сбоку/сверху/снизу, вид из салона.
- **Режимы**: обычный, прозрачный кузов, разрез (снята правая половина кузова), пошаговая разборка (13 шагов), вид снизу.
- **Кузов**: открываются двери, капот, дверь багажника, опускаются стёкла.
- **Свет**: габариты, ближний, поворотники, аварийка, стоп-сигналы, задний ход.
- **Выбор деталей касанием** и интерактивные точки → карточка детали → полное описание.
- **Управление объектами**: подсветка, «только эта деталь», скрыть, показать всё.
- **База знаний**: 88 деталей в 10 системах, у каждой 8 разделов (назначение, принцип, расположение, связи, неисправности, признаки, обслуживание) и отметка достоверности.
- **«Мой Rezzo»**: выбор кода двигателя (не подтверждён — A16DMS / F16D3 / L44 / свой), мощности (90 / 105 / 107 л.с.), ABS; характеристики с источниками.
- **Импорт своей 3D-модели** (GLB/glTF) без пересборки; при ошибке — возврат к заглушке, приложение не падает.
- Room (прогресс изучения, таблицы гаража на будущее), DataStore (настройки).

## Честно о 3D-модели

Сейчас показана **учебная заглушка**: габариты по паспорту, форма и размещение агрегатов условные.
Готовой лицензированной модели Rezzo в проекте нет. Требования к настоящей модели — `docs/ASSETS.md`.

## Архитектура

```
:core     модели данных, база знаний (assets/kb/*.json), Room, DataStore — без UI
:scene3d  3D-движок: Filament, загрузка GLB, камера, анимации узлов, выбор касанием — без UI
:app      Jetpack Compose: навигация, экраны, связывание модулей
tools/    генератор учебной 3D-модели (python3 tools/gen_placeholder_car.py)
```

Логика 3D-модели (что открывается, что светит, какой узел — какая деталь, шаги разборки, точки)
описана в `app/src/main/assets/scene/car_scene.json`, а не в коде.

## Сборка

APK собирается GitHub Actions при каждом пуше: вкладка Releases → «Последняя сборка» (`RezzoAcademy.apk`)
или ветка `apk`. Лог последней сборки — ветка `ci-log`.
Ключ подписи `app/dev.keystore` постоянный, поэтому обновления ставятся поверх без потери данных.

## Точность данных

Технические характеристики помечены: «Подтверждено», «Зависит от версии», «По данным Tacuma», «Не подтверждено», «Общий принцип».
Моменты затяжки, номера деталей, электросхемы и регламенты не выдумываются — где данных нет, это написано прямо.
Данные двухлитровой версии не используются.
